# 更新日志

## 版本 2.0

### 添加的功能:

#### 全局配置页面
- **项目标签配置**: 用户可以定义和更新项目标签键，以便在不同的部署单元中组织GameServerSet和GameServer，确保适当的组织和功能。
- **部署单元管理**: 允许用户添加或删除仪表板管理的部署单元列表中的Kubernetes集群。

#### 项目页面
- **项目列表**: 以表格格式显示所有项目，显示项目信息，如项目名称、GameServerSet数量、GameServer数量以及关联的部署单元。
- **跨部署单元管理**: 允许在单个项目内跨多个部署单元管理GameServerSet和GameServer。
- **资源监控**: 跟踪每个项目中的资源分配和使用情况，以确保高效的资源利用。
- **操作控制**: 用户可以在项目内执行操作，例如扩展GameServerSet、更新容器镜像以及部署新配置。

#### 部署单元页面
- **部署单元概览**: 列出所有部署单元，并显示详细信息，例如部署单元名称、GameServerSet数量、GameServer数量以及关联的项目。
- **跨集群管理**: 管理跨多个部署单元的GameServerSet，以保持稳定和可扩展的部署环境。
- **详细部署单元管理**: 访问特定部署单元的详细概览，以管理GameServer和GameServerSet，包括扩展和配置更新。

#### 添加资源页面
- **资源创建**: 通过在仪表板内直接编写或上传YAML文件来创建和定制新的Kubernetes资源。
- **下载和部署**: 编写或上传YAML文件后，用户可以一键保存或部署配置的资源。

#### GameServerSet表页面
- **综合列表**: 查看选定项目内的所有GameServerSet，并在列中显示关键信息，例如副本数量、更新策略和状态。
- **批量操作**: 对多个GameServerSet执行批量操作，包括更新容器镜像和删除GameServerSet。
- **项操作**: 管理单个GameServerSet，包括扩展、更新配置和删除GameServerSet等操作。

#### GameServer表页面
- **GameServer列表**: 查看选定项目内所有GameServer的详细列表，包含运行状态、资源使用情况和操作状态等信息。
- **实例级别控制**: 管理单个GameServer，包括重启、更新或删除特定实例的操作。
- **批量操作**: 对多个GameServer执行批量操作，包括删除服务器、更新容器镜像、调整资源分配、设置更新和删除优先级。
- **项操作**: 执行单个GameServer的特定操作，例如删除GameServer或更新其容器镜像。
